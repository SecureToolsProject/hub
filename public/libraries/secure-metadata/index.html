Overview

A bounded metadata component

Secure Metadata provides reusable local inspection, cleaning, and verification for documented JPEG, WebP, and PNG structures. Products can vendor the library while retaining responsibility for their own UI, workflow, storage, and release guarantees.

Metadata results are not universal privacy proof

Supported reporting is intentionally bounded. Unsupported, opaque, proprietary, steganographic, or undetected information may remain. Absence of recognized metadata does not prove that an image contains no private information.
