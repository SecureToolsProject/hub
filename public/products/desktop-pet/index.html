Overview

A desktop product with its own lifecycle

The current project is a lightweight always-on-top 2D companion. Its repository owns desktop behavior, packaging decisions, testing, and eventual release terms. The Hub does not assign it a release date or download link.

Local operation is a bounded statement

Desktop-local processing does not automatically prove that every future release has zero network activity. The current development documentation describes no accounts, cloud services, updater, analytics, telemetry, or background runtime network access; exact release behavior must be disclosed again before release.
