Design considerations

Questions the product must answer

A local AI application can have heavier runtime and storage requirements than a browser utility. The product must document these boundaries without being folded into the Web Utilities runtime.

  • Whether inference runs locally, remotely, or in a hybrid arrangement.
  • How models are acquired, verified, updated, and stored.
  • Whether browser cache, WebGPU, native runtimes, or application storage are required.
  • Which network requests are optional, required, or user-initiated.
  • Whether telemetry exists and how users can understand or control it.

Source and documentation

Not publicly linked. No public Secure Local AI repository or release documentation is currently available through the organization catalog. Source, license, entry point, and technical documentation must be added when they are established.

Release disclosure will take precedence

These considerations are not promises about a future implementation. A product release must publish its actual processing, network, storage, model, telemetry, platform, and update behavior.
