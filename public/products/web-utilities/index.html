Overview

Bounded local file workflows

The application provides documented PDF, image, and metadata tools. Local processing claims apply to supported production workflows and formats; they do not claim universal sanitization, anonymity, or protection from every browser, operating-system, extension, or file behavior.

Website delivery and file processing are different

Visiting the site requires ordinary network requests for its static application files. Once loaded, supported production file-processing workflows operate in the browser and do not send file contents to an application upload service.

Entry point and migration boundary

Current site: securetools.app currently serves Web Utilities. A later ecosystem migration may move this product, but no future subdomain is linked or implied here.
