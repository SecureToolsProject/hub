A software ecosystem

Local-first tools with clear boundaries.

Secure Tools is a collection of independently maintained, privacy-conscious products and libraries. The project favors local processing where practical, understandable network behavior, and implementations people can inspect.

Principles

How the ecosystem is shaped

  • Local-first processing where practical
  • Minimal unnecessary data exposure
  • Transparent network behavior
  • Privacy-aware defaults
  • Auditable, open implementation where practical
  • Traceable deployment

Exact privacy and network behavior varies by product and must be documented by each project.
