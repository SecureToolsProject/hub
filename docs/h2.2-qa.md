# H2.2 quality assurance

This record covers the Brand Alignment & Production Visual Polish change on
`feat/hub-brand-alignment`. It does not record a deployment or production-domain migration.

## Route matrix

The following static routes were validated from the repository and served from a local HTTP
server on 2026-09-01:

- `/`
- `/products/`
- `/products/web-utilities/`
- `/products/desktop-pet/`
- `/products/local-ai/`
- `/libraries/`
- `/libraries/secure-metadata/`
- `/principles/`
- `/principles/privacy/`
- `/project/`
- `/404.html`

Every route returned HTTP 200 when addressed directly. Automated source checks passed for one
header, main, and footer landmark per route; unique IDs; same-page fragment targets; internal
route and asset resolution; shared stylesheet and favicon loading; and absence of JavaScript.

## Metadata and assets

Each route's document title and description match its Open Graph and X/Twitter title and
description. Every route uses the Hub-specific 1200×630 social preview and the local SVG
favicon. The social card was inspected at a reduced preview size: both required text strings
were exact, legible, and free of extra text, and its neutral, green-signal, independent-card
composition matched the implemented visual system.

No canonical link or `og:url` is present. The absolute social-image reference uses the current
Cloudflare Pages validation origin only; it does not identify that origin as the permanent Hub
URL or change the documented production-domain boundary.

## Responsive and accessibility checks

Static CSS review confirmed:

- shared light and dark theme tokens with sufficient separation of text, surfaces, borders,
  accent, and focus colors;
- a global three-pixel `:focus-visible` outline with offset;
- 52rem and 38rem layout transitions for header, navigation, split layouts, cards,
  disclosures, actions, and footer links;
- shrinkable grid children, wrapped navigation and action groups, safe word wrapping, and a
  20rem minimum viewport contract;
- reduced-motion handling that removes scroll and card movement; and
- semantic headings, landmarks, lists, disclosure lists, breadcrumb labels, current-page
  states, and a working skip-link target in the page source.

## Browser limitation

Interactive browser automation was attempted against `http://127.0.0.1:4173/`. The browser
runtime stopped before navigation with `failed to write kernel assets: The system cannot find
the path specified. (os error 3)`. Therefore no automated claim is made for rendered layout,
actual color-scheme switching, pointer interaction, keyboard traversal, or viewport screenshots.

Before production-domain migration, complete a human browser review at 320, 390, 768, 1024,
and 1440 CSS pixels in light and dark system themes, including keyboard-only traversal and
zoomed text. This limitation does not change the static validation results above.
